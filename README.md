# RapidMind AI — Vanilla

This is the HTML/CSS/JavaScript version of the RapidMind AI crisis-intelligence demo.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Scenarios
- Fire
- Medical Emergency
- High-Risk Security Threat
- Crowd Risk
- Gas Leak

## Note
This version removes React, TypeScript, JSX, Tailwind, Lucide React and Motion dependencies. The current frontend uses the project's demo/simulation data and does not expose a Gemini API key in browser code.
