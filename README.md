# RapidMind AI

RapidMind AI is a crisis intelligence and emergency response simulation interface designed to demonstrate how incident telemetry can be converted into actionable response information.

## Features

- Crisis scenario simulation
- Incident classification
- Risk assessment
- Predictive risk indicators
- Tactical route visualization
- Emergency response coordination
- Vulnerable-group identification
- Real-time response timer
- Responsive dashboard layout

## Technology

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)

No frontend framework is required to run the current prototype.

## Run Locally

Open `index.html` directly in a browser or use a local development server such as VS Code Live Server.

## Scenarios

The prototype includes Fire, Medical Emergency, High-Risk Security Threat, Crowd Risk and Gas Leak scenarios.
